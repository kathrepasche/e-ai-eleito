# Logos

Logo "Depois do FIM": a tela da urna com FIM riscado e o balão amarelo "E aí?".

- `icone-completo.svg`: use a partir de 96px.
- `icone-simplificado.svg`: use abaixo de 96px; o balão leva "?".
- `logo-horizontal.svg`: ícone com o nome, para cabeçalho e documentos. Sobre fundo escuro, troque o texto do nome para #F7F5F0.

Área de respiro mínima: 1/4 da altura do ícone em volta. Não mude as cores, não aplique sombra e não troque a urna pelas cores reais das teclas. Os textos usam fonte do sistema; converta em curvas antes de imprimir.
